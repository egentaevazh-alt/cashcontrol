Cashcontrol iPhone PWA — GitHub Pages

1. Распакуйте архив.
2. Загрузите index.html, manifest.webmanifest, sw.js и папку icons в КОРЕНЬ репозитория mubudget.
3. В GitHub Pages убедитесь, что публикация идёт из нужной ветки и папки.
4. Откройте https://egentaevazh-alt.github.io/mubudget/ в Safari на iPhone.
5. Нажмите Поделиться → На экран «Домой» → Добавить.

Важно: PWA не заменяет iOS-приложение App Store. Offline поддержка ограничена оболочкой; Supabase, обменные курсы и импорт PDF требуют интернет/внешние ресурсы. Данные защищаются только при корректной Supabase авторизации и RLS.
